# Світло — графік ДТЕК на заблокованому екрані

Невеликий Android-застосунок для Києва. Бере графік стабілізаційних відключень
з офіційного сайту ДТЕК Київські електромережі і показує його:

- **у постійному сповіщенні** зі шкалою на 24 години (від години тому і на добу вперед)
  і зворотним відліком до наступного вмикання чи вимикання;
- **на Android 16 / One UI 8** — як Live Update: коротке «до 16:30» у Now Bar на
  заблокованому екрані та в чипі біля годинника;
- **у віджеті** для головного екрана.

## Звідки дані

- `https://www.dtek-kem.com.ua/ua/shutdowns`: у HTML є `DisconSchedule.fact` — погодинний
  графік усіх черг на сьогодні й завтра (`yes` / `no` / `first` / `second`).
- `POST /ua/ajax`, `method=getHomeNum`: черга для адреси (`GPV1.1`) і поточне
  відключення (зокрема аварійне, якого немає в графіку).

Оновлення раз на 15 хвилин (WorkManager), плюс будильник на момент зміни стану,
щоб сповіщення перемикалося вчасно навіть без інтернету.

## Збірка через GitHub (без Android Studio)

1. Зробіть форк цього репозиторію (або створіть свій і запуште туди цю папку).
2. Вкладка **Actions** → workflow «Build APK» запуститься сам.
3. Після завершення відкрийте запуск → **Artifacts** → `svitlo-apk` → там `app-release.apk`.
4. Скиньте APK на телефон і встановіть (дозвольте встановлення з цього джерела).

Ключ підпису в репозиторії не зберігається. Щоб нові збірки ставилися поверх старих, додайте в Settings → Secrets and variables → Actions три секрети: `SVITLO_KEYSTORE_B64` (файл .jks у base64), `SVITLO_STORE_PASSWORD` і `SVITLO_KEY_PASSWORD`. Без них APK підписується стандартним debug-ключем.

## Збірка в Android Studio

Відкрийте папку → Build → Generate APKs (або Run на підключеному телефоні).

## Після встановлення на Samsung

1. Відкрийте застосунок, дозвольте сповіщення.
2. Натисніть «Дозволити роботу у фоні» (інакше One UI може приспати оновлення).
3. Налаштування → Сповіщення → Світло: переконайтеся, що сповіщення показуються на
   заблокованому екрані. На One UI 8 увімкніть для застосунку Live notifications / Now Bar,
   якщо такий перемикач є.
4. За бажання додайте віджет «Світло» на головний екран.

Адресу можна змінити в застосунку (формат як на сайті ДТЕК: `вул. Хрещатик`, `1`).
